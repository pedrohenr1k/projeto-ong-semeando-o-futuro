## 🚀 Fases do Projeto  

### 🧱 **Atividade 1: Estrutura com HTML5**  
Criação da base estrutural do site utilizando **HTML5 semântico**, garantindo uma marcação **acessível**, **organizada** e **significativa**.  
Incluiu o uso correto de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.

---

### 🎨 **Atividade 2: Estilização com CSS3**  
Transformação da estrutura HTML em uma interface visual **profissional** e **responsiva**, utilizando:  
- **CSS Grid** e **Flexbox** para organização dos elementos;  
- **Variáveis CSS** para padronizar cores e tipografia;  
- **Componentes interativos** e **design responsivo**.  

---

### ⚙️ **Atividade 3: Dinamismo com JavaScript Avançado**  
Adição de **interatividade e dinamismo** ao site, implementando:  
- Um sistema de **SPA (Single Page Application)** básico que evita o recarregamento total da página;  
- **Validação de formulários** em tempo real com feedback visual;  
- **Manipulação do DOM** e **gerenciamento de eventos** com código modular.  

---

## 🌍 **Atividade 4: Versionamento, Acessibilidade e Otimização (Entrega Final)**  

Esta entrega final consolida o projeto com práticas profissionais de **desenvolvimento, acessibilidade e otimização para produção**.  

### 🧩 1. Controle de Versão com Git/GitHub  
- **Estratégia de Branching:** Implementação do modelo **GitFlow**, com branches:  
  - `main` → produção  
  - `develop` → desenvolvimento  
  - `feature/*` → novas funcionalidades  
- **Commits Semânticos:** Adoção de mensagens padronizadas (ex: `feat:`, `fix:`, `refactor:`) para clareza e rastreabilidade.  
- **Releases:** Criação de versões estáveis com **versionamento semântico** (ex: `v1.0.0`) publicadas no GitHub.  

---

### ♿ 2. Acessibilidade (WCAG 2.1 Nível AA)  
- **Navegação por Teclado:**  
  Todos os elementos interativos (links, botões e inputs) possuem estados visuais de `:focus`, garantindo total usabilidade sem o uso do mouse.  
- **Contraste e Temas:**  
  Implementação dos **modos Claro e Escuro**, respeitando a preferência do usuário e salvando-a via `localStorage`.  
  As cores foram testadas para atender ao contraste mínimo de **4.5:1**, conforme as diretrizes **WCAG 2.1 - Nível AA**.  
- **Leitores de Tela:**  
  Estrutura semântica e uso adequado de `alt` em imagens e elementos ARIA para melhor compatibilidade com tecnologias assistivas.  

---

### ⚡ 3. Otimização para Produção  
- **Minificação:**  
  Preparação dos arquivos CSS e JS para minificação, removendo espaços e caracteres desnecessários, reduzindo o tempo de carregamento.  
- **Compressão de Imagens:**  
  Todas as imagens foram otimizadas e comprimidas antes do deploy, garantindo melhor desempenho.  
- **Boas Práticas de SEO:**  
  Uso de meta tags, títulos descritivos e estrutura semântica para melhor indexação em buscadores.
